# Brand asset

logo.png is the user-approved SeferihisarOfficial profile logo created with the built-in image generation tool. The renderer composites this original file into every feed and story header. Individual illustrations never redraw the logo.

There is no shared landscape/news backdrop. Per-item illustrations are passed explicitly to the renderer and labelled Temsili çizim. Missing matching media produces an abstract brand/text card. Cloud generation and its billing credentials have not been enabled.
